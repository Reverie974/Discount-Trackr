## Overview
Discount Finder is a personal project inspired by student discount platforms such as UNiDAYS. It helps users discover brands offering discounts on products they're interested in buying, with search and category-based browsing to make finding relevant offers easier.

The application uses Next.js for the frontend and Supabase for backend services and database integration, with PostgreSQL managing the underlying relational data.

Users can search for specific products, such as laptops, to discover relevant brands offering discounts. Each brand listing includes a link to the relevant page where users can access or redeem the offer.

Features:
* Search for brands by product
* Browse brands by category
* View brand listings and follow links to offers
  
Tech Stack:
* Frontend: Next.js
* Backend and database services: Supabase
* Database: PostgreSQL

Future Improvements:
* Expand the database to include more brands and discounts
* Enable users to click on brand cards to view more details
* Explore personalised brand recommendations

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started
First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
